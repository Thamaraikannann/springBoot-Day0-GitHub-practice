## ⚡ Git Commands Used

### Initialize Git

```bash
git init
```

### Add Files

```bash
git add .
```

### Commit Files

```bash
git commit -m "feat: added project files"
```

### Connect GitHub Repository

```bash
git remote add origin https://github.com/yourusername/springBoot-Day0-GitHub-practice.git
```

### Rename Branch

```bash
git branch -M main
```

### Push to GitHub

```bash
git push -u origin main
```
